# TG Selfhost Bot API

Официальный Telegram Bot API сервер в Docker: собственный entrypoint, патч
User-Agent для webhook и инструменты миграции.

## Инструкции

- [Установка](getting-started.md) — запуск, локальная сборка или готовый образ, проверка сервиса.
- [Настройки](configuration.md) — порты, переменные, файлы и доступ.
- [Миграция](migration.md) — переходы между облаком и локальными серверами, ограничения утилит.
- [Обслуживание](maintenance.md) — обновления, резервные копии, диагностика и документация.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| Официальный сервер tdlib | Реализует Bot API |
| Образ этого проекта | Собирает сервер, применяет патч webhook и запускает его с настройками из окружения |
| nginx | Проксирует HTTP-запросы к серверу |
| Host CLI doctor | Проверяет установку и предпосылки миграции, выводит безопасный text/JSON отчёт |
| Python-исполнитель | Неизменяемый plan/apply/status/resume для четырёх направлений |
| Bash-утилита | Совместимый адаптер к общему исполнителю |
| Браузерный инструмент | UI loopback helper на одном origin; Pages остаётся входной страницей |

Сборка не зависит от aiogram. Их проект упаковывает тот же официальный сервер;
здесь используется собственная Docker-упаковка.

Сейчас образ поддерживает `linux/amd64`. Для публикации и ночного обновления
workflow должен попасть в основную ветку и успешно выпустить первый образ.
Наличие имени образа в Compose само по себе не означает, что он уже опубликован.

Дальнейшая работа собрана в [issues](https://github.com/ichinya/tg-selfhost-botapi/issues/19).
