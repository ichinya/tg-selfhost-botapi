TG Selfhost BotAPI Migrator

Удобный инструмент для миграции ботов между серверами

1. Режим миграции

Official → Self
Self → Self
Self → Official
Webhook only
Official → Self: Переезд с api.telegram.org на свой Bot API. Включает logOut на official.

Polling всегда удаляет webhook на target. Preserve в Webhook only выполняет только чтение. Очистка URL не меняет действие.

Поля ниже активны для set и восстановления webhook при переносе preserve. Для polling они игнорируются.

Source detach всегда drop=false. True необратим; false не гарантирует перенос очереди. Для read-only preserve drop неприменим.

Запросы с токеном требуют подтверждения. При CORS/UNKNOWN сначала сверяйте состояние вручную; повторный план может повторить уже выполненную операцию.

2. Быстрые проверки

Формат токена: не проверено
Старый API: не проверено
Новый API: не проверено
Webhook URL: не проверено
Сертификат: не проверено
CORS: best effort

5. Curl-план

Для cloud → local и webhook-only: Bash-план с подтверждением и проверкой ответов. Для local → local и local → official: отдельные ручные этапы; автоматическое выполнение отключено. 
Сначала выбери режим и нажми «Проверить состояние».
