Запустите локальный helper / Start the local helper

Эта публичная страница и file:// не выполняют запросы Bot API или localhost. Linux/WSL, Python 3.11+, приватные state/evidence/provider files обязательны.

python3 tools/migration_helper.py --config "$HELPER_CONFIG" --port 8765

Откройте http://127.0.0.1:8765/ и введите одноразовый код из терминала. Для удалённого хоста используйте SSH tunnel. English setup · Инструкция

Доступ оператора / Operator session

1 · Входы плана / Plan inputs
2 · Приватные подтверждения / Private provider receipts

Signed provider JSON. Plain text and checkboxes do not prove external actions. Retain the original authority and backup. Full preserve without verified original private settings stays blocked.

3 · Неизменяемая операция / Sealed operation

Проверьте ID, digest, шаги, action/drop и checkpoints. Для apply/resume введите показанный digest. Потеря ответа UI требует status этой же операции. UNKNOWN detach/drop требует evidence.

Состояние / State

Service readiness ≠ migration outcome ≠ webhook configuration ≠ delivery. HTTP 200 and matching URL do not prove delivery.
