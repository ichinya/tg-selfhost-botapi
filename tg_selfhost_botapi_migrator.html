TG Selfhost BotAPI Migrator

Удобный инструмент для миграции ботов между серверами

1. Режим миграции

Official → Self
Self → Self
Self → Official
Webhook only
Official → Self: Переезд с api.telegram.org на свой Bot API. Включает logOut на official.
Примечание: выполнение команд в браузере может быть заблокировано CORS. В случае ошибки используйте curl-план ниже.

2. Быстрые проверки

Формат токена: не проверено
Старый API: не проверено
Новый API: не проверено
Webhook URL: не проверено
Сертификат: не проверено
CORS: best effort

5. Curl-план

План предназначен для Bash в Linux/WSL, не для PowerShell. Сохраните его в UTF-8 с переводами строк LF как migration-plan.sh и запустите bash ./migration-plan.sh. Токен вводится скрыто или берётся из BOT_TOKEN. Кнопка "Выполнить команды" пытается сделать это прямо в браузере (но может быть заблокировано CORS). 
Сначала выбери режим и нажми «Проверить состояние».
